01

Data & Input Initialization

Initial state configured with Laptop ($800) and Mouse ($25). Implements native prompt() and form validation with numerical type casting via Number(price).

Control Flow (if...else & switch)

Conditional branches categorize items into Budget (<$100), Standard ($100-$500), and Premium (>$500). Analytical reporting is routed through a rigorous switch statement.

03

Loops (break & continue)

Demonstrates iteration with for loops. Skips non-matching items using continue and halts evaluation upon exact match using break with live console trace.

04

Functions & Local Scope

Combines declaration functions with modern arrow functions. Demonstrates function-level lexical scope for tax and discount calculations without global state leakage.

05

Array Methods (forEach, filter, map)

Utilizes forEach() for DOM rendering, filter() for items <$200, and map() to project string arrays like "LAPTOP: $800".
